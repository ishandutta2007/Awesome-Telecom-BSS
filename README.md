# Awesome-Telecom-BSS

## Top Telecom BSS Tools Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**

*Focused on Telecom Business Support Systems, Billing, Charging, Revenue Management & Monetization*

**Last updated: August 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Telecom BSS (Business Support Systems)**. These systems handle rating, charging (OCS), mediation, invoicing, customer management, order management, and revenue assurance for communications service providers, MVNOs, and digital telcos.



**Examples** include Amdocs, Netcracker, CSG, Optiva, Oracle Communications, Ericsson Billing, Comarch Telecom, Hansen Technologies, Sterlite Technologies, and DigitalRoute (the category leaders).



**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, real-time charging engines, CDR mediation, and open BSS stacks — ideal for operators, integrators, researchers, and developers building transparent, customizable telecom monetization solutions.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects

- **[CGRateS](https://github.com/cgrates/cgrates)**  

  High-performance real-time Online/Offline Charging System (OCS) for telecom and ISP environments with rating, balances, CDR, LCR, and fraud detection.



- **[BillRun](https://github.com/BillRun/system)**  

  Open-source enterprise telecom BSS with real-time OCS, CDR mediation, rating/charging (prepaid/postpaid), invoicing, and fraud detection.



- **[ASTPP](https://astppbilling.org/)**  

  Carrier-grade open-source telecom billing and softswitch platform combining BSS, OCS, Class 4/5 switching, LCR, and real-time CDR processing.



- **[SigScale OCS](https://github.com/sigscale/ocs)**  

  3GPP-compliant Online Charging System with AAA (DIAMETER/RADIUS), real-time charging, and TM Forum Open API support.



- **[A2Billing](https://github.com/Star2Billing/a2billing)**  

  Mature open-source telecom switch and billing system for calling cards, VoIP termination, DID resale, and callback services.



- **[Kill Bill](https://github.com/killbill/killbill)**  

  Modular open-source billing and payment platform supporting subscriptions, usage-based charging, and extensible plugins.



- **[jBilling](https://sourceforge.net/projects/jbilling/)**  

  Open-source enterprise billing system with CDR mediation capabilities suitable for telecom and subscription scenarios.



- **[OpenBRM / related rating engines](https://openbrm.com/)**  

  Open-source billing and CRM stack with integrated high-speed rating (OpenRate) for telecom mediation and converged charging.



- **[CDRTool](https://github.com/AGProjects/cdrtool)**  

  CDR mediation and rating engine for processing Call Detail Records in VoIP and telecom environments.



- **[telecom-provision-engine](https://github.com/kambidi1973/telecom-provision-engine)**  

  Microservices-based open-source telecom OSS/BSS provisioning and order management platform with billing and inventory components.



### Additional Strong Open-Source Options

- **[FreeSBC](https://github.com/aicc2025/FreeSBC)** — Session Border Controller with built-in carrier-grade call accounting and real-time billing primitives.

- Community **Diameter/RADIUS AAA** stacks, **mediation engines**, and **TM Forum Open API** implementations.

- **Osmocom** and related open telecom projects for core network and supporting BSS functions.

- Many **VoIP billing** forks and **usage-based metering** tools (e.g., OpenMeter-style) adaptable to telecom.

- Academic and operator-contributed **rating engines** and **fraud detection** modules on GitHub.



**Frameworks for building custom systems**: Combine **CGRateS** or **BillRun** for core charging/rating, **SigScale OCS** for 3GPP compliance, **ASTPP** or **A2Billing** for softswitch integration, **PostgreSQL/MongoDB** for data, **Kafka** for event streaming, and **Ollama**/local LLMs for intelligent fraud detection, customer insights, and automated tariff recommendations.
